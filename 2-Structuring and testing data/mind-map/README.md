# Structuring and testing data mind map

An interactive map of every assignment in the Structuring and testing data module (weeks 4-6): preparation exercises, the lesson-plan workshops, the Module-Structuring-and-Testing-Data coursework issues and the Sprint exercise files they point to.

- Hover a node to see a short summary of what to do.
- Click a node to open the exact section, issue, folder or file on GitHub.
- Search, expand/collapse branches and zoom from the toolbar.

**Open it:** https://hackyourfuturebelgium.github.io/Intro-to-Programming/2-Structuring%20and%20testing%20data/mind-map/

Published by `.github/workflows/pages.yml`, together with the Onboarding mind map.

## Updating

`index.html` is self-contained: the map data is the `TREE` object near the top of the `<script>`. Each node has a title (`t`), kind (`k`), link (`u`), summary (`s`) and children (`c`). Edit it when the curriculum, the coursework issues or the Sprint exercises change.
